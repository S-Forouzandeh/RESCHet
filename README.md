# RESCHet

**Recommendation Based on Embedding Spectral Clustering in Heterogeneous Networks**

> Forouzandeh, S., Berahmand, K., Sheikhpour, R., & Li, Y. (2023).  
> *Expert Systems with Applications*, 231, 120699.  
> https://doi.org/10.1016/j.eswa.2023.120699

---

## Overview

RESCHet is a two-stage recommender-system framework for **Heterogeneous Information Networks (HINs)** containing multiple node types (e.g. users, movies, directors).

```
HIN  →  Metapath2Vec  →  Non-linear Fusion  →  Embedding Spectral Clustering
      →  Atomic / Submeta-paths  →  Hadamard Product  →  Recommendation
```

### Stage 1 — HIN Embedding + Fusion (Sections 4.1 & Eq. 7)

Metapath2Vec random walks are performed along each meta-path (e.g. `U→M→U`, `U→M→D→U`).  
The resulting per-path embeddings are combined with a non-linear fusion function:

$$g\!\left(\{e_u^{(l)}\}\right) = \sigma\!\left(\sum_{l=1}^{|P|} w_u^l\,\sigma\!\left(M^l e_u^{(l)} + b^l\right)\right)$$

### Stage 2 — Embedding Spectral Clustering (Section 4.2)

1. Cosine similarity matrix **S** from fused user embeddings.  
2. Graph Laplacian **L = D − S**.  
3. Eigengap heuristic selects *k*.  
4. K-means on the *k* leading eigenvectors.

### Stage 3 — Cluster-aware Recommendation (Section 4.3, Eqs. 8–10)

Three submeta-path pairs are defined per cluster and their embeddings combined via Hadamard (element-wise) product:

| Eq. | Expression | Captures |
|-----|-----------|---------|
| 8 | `E_UM  = e^UU(M) ⊙ e^MM(U)` | Users sharing movies |
| 9 | `E_D   = e^UU(D) ⊙ e^MM(D)` | Users / movies sharing directors |
| 10 | `E_UMD = e^UU(MD) ⊙ e^MM(UD)` | Combined user–director–movie relations |

Final recommendations are generated by cosine similarity within each user cluster.

## Dataset Setup

### MovieLens (demo / development)

```bash
mkdir -p data
wget https://files.grouplens.org/datasets/movielens/ml-latest-small.zip
unzip ml-latest-small.zip -d data/
```

Directory expected at `data/ml-latest-small/`.

### Douban Movie / Book · Yelp (paper benchmarks)

Download the preprocessed files from the original repository and place them under `data/douban_movie/`, `data/douban_book/`, `data/yelp/`.

Each directory should contain at minimum:
- `ratings.csv` — columns: `userId`, `movieId`, `rating`
- `movies.csv`  — columns: `movieId`, `title`, `director`

## Quick Start

```python
from data_utils import load_movielens
from reschet import RESCHet

# 1. Build the HIN
hin, ratings_df = load_movielens("data/ml-latest-small")

# 2. Train RESCHet
model = RESCHet(
    embedding_dim=128,
    walk_length=40,
    num_walks=5,
    window=5,
    max_k=15,
    top_n=10,
)
model.fit(hin)

# 3. Recommend
user_item_ratings = {
    f"u_{row.userId}": {} for _, row in ratings_df.iterrows()
}
for _, row in ratings_df.iterrows():
    user_item_ratings[f"u_{row.userId}"][f"m_{row.movieId}"] = row.rating

recs = model.recommend("u_1", user_item_ratings, top_n=10)
print("Top-10 for user 1:", recs)

# 4. Evaluate (MAE / RMSE)
results = model.evaluate(ratings_df, train_ratios=[0.2, 0.4, 0.6, 0.8])
print(results)
```

## Key Hyperparameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `embedding_dim` | 128 | Metapath2Vec / Word2Vec vector size |
| `walk_length` | 40 | Steps per random walk |
| `num_walks` | 5 | Walks per seed node |
| `window` | 5 | Skip-gram context window |
| `max_k` | 15 | Maximum number of spectral clusters |
| `top_n` | 10 | Number of recommended items |
| `workers` | 4 | Word2Vec training threads |

## Results (from paper)

Best performance at 80 % training ratio:

| Dataset | MAE | RMSE |
|---------|-----|------|
| Douban Movie | **0.5388** | **0.6890** |
| Douban Book | **0.5467** | **0.6801** |
| Yelp (90 %) | **0.7810** | **1.0192** |

RESCHet consistently outperforms PMF, SoMF, HeteMF, SemRec, DSR, HERec, HetNERec, and HopRec on all three benchmarks.

## Differences from the Original Code

The original script had several issues that have been corrected:

| Issue | Fix |
|-------|-----|
| IMDB web-scraping to obtain directors | Removed; directors read from CSV or genres used as proxy |
| `StellarGraph` / `GraphSAGE` used in place of Metapath2Vec | Replaced with proper meta-path random walks + `gensim.Word2Vec` |
| `ground_truth_ratings.iterrows()` called on a NumPy array | Fixed; DataFrame API used only on DataFrames |
| `cluster_meta_paths.append(tuple)` syntax error | Fixed to use a list of lists |
| `pairwise_distances` called with unsupported keyword `X_norm` | Removed; `sklearn.metrics.pairwise.cosine_similarity` used directly |
| `LinearRegression` used as the recommendation predictor | Replaced with cosine-similarity weighted-average (standard CF baseline) |
| No proper non-linear fusion implementation | `NonLinearFusion` class added, implementing Eq. 7 |
| No eigengap heuristic for cluster count | `EmbeddingSpectralClustering._eigengap()` added |
| Single monolithic script | Refactored into `reschet.py`, `data_utils.py`, `main.py` |
